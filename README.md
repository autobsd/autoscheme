# AutoScheme

AutoScheme is a dialect of the Scheme programming language designed to provide enhanced automation and integration capabilities. It aims to be a powerful tool for scripting, automation, and extending existing systems with Scheme's expressive syntax and powerful macro system.

AutoScheme comprises a command-line application and an embeddable C library that provide the following:

- a Scheme interpreter
- an S2S compiler (Scheme to C/C++)
- a set of modules that implement and extend a subset of the R7RS standard
